# APK 自动化测试工具 — 支持多 APK 文件改动说明

## 1. 改动概述

在原有单 APK 测试的基础上，新增了对**文件夹内所有 APK 文件**进行批量测试的能力。用户可以通过 `--apk-dir` 参数指定一个文件夹，工具会自动扫描该文件夹内所有 `.apk` 后缀的文件，并逐个执行完整的测试流程。

| `core.py` | 新增 `run_tests_batch()` 函数 |
| `cli.py` | 新增 `--apk-dir` 参数，修改 `cmd_run()` 支持文件夹模式 |

## 3. 新增函数：`run_tests_batch()`

### 3.1 函数签名

```python
def run_tests_batch(devices, apk_paths, run_minutes=5, switch_times=2,
                    relaunch_times=3, skip_install=False, skip_uninstall=False,
                    max_workers=None):
```

### 3.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `devices` | `list[str]` | - | 设备序列号列表 |
| `apk_paths` | `list[str]` | - | APK 文件路径列表 |
| `run_minutes` | `int` | 5 | 运行监控时长（分钟） |
| `switch_times` | `int` | 2 | 前后台切换次数 |
| `relaunch_times` | `int` | 3 | 杀进程重启次数 |
| `skip_install` | `bool` | False | 跳过安装步骤 |
| `skip_uninstall` | `bool` | False | 跳过卸载步骤 |
| `max_workers` | `int` | None | 并行设备数，默认全部同时 |

### 3.3 返回值

```python
Dict[str, Dict[str, bool]]
# 结构: {apk_path: {device: True/False, ...}, ...}
```

### 3.4 执行逻辑

```
输入: APK 文件路径列表

1. 遍历每个 APK 文件（带进度 [i/N]）
   ├── 输出当前 APK 名称和路径
   ├── 调用 run_tests() 执行完整测试流程
   └── 输出当前 APK 的阶段性汇总（通过/失败数）

2. 输出全部 APK 的最终汇总
   ├── 每个 APK 的通过率
   └── 总通过率
```

## 4. CLI 改动

### 4.1 新增参数

| 参数 | 缩写 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--apk-dir` | - | 二选一 | None | APK 文件夹路径，自动扫描所有 .apk 文件 |

### 4.2 参数校验逻辑

```python
if not args.apk and not args.apk_dir:
    print("❌ 请指定 --apk（单文件）或 --apk-dir（文件夹）")
    return 1
if args.apk and args.apk_dir:
    print("❌ --apk 和 --apk-dir 不能同时使用，请二选一")
    return 1
```

- `--apk` 和 `--apk-dir` 必须且只能使用其中一个
- 两个都未指定 → 报错退出
- 两个都指定 → 报错退出

### 4.3 文件夹扫描逻辑

```python
apk_paths = sorted([
    os.path.join(args.apk_dir, f)
    for f in os.listdir(args.apk_dir)
    if f.lower().endswith(".apk")
])
```

- 使用 `os.listdir()` 扫描文件夹
- 过滤出以 `.apk` 结尾的文件（不区分大小写）
- 按文件名排序，保证执行顺序可预期
- 未找到任何 APK 时报错退出

### 4.4 执行分支

```python
if len(apk_paths) == 1:
    # 单 APK 模式 → 调用 run_tests()，保持原有逻辑
    results = run_tests(...)
else:
    # 批量模式 → 调用 run_tests_batch()
    results = run_tests_batch(...)
```

- 文件夹内只有 1 个 APK 时，走原有的单 APK 逻辑
- 文件夹内有多个 APK 时，走新增的批量逻辑

---

## 5. 使用示例

```bash
# 文件夹批量测试
apk-test run --apk-dir ./apks --device 45a2cacc

# 文件夹 + 多设备
apk-test run --apk-dir ./apks --device 45a2cacc,FA7831801432

# 文件夹 + 自定义参数
apk-test run --apk-dir ./apks --device 45a2cacc --minutes 3 --switch 3 --relaunch 5

# 单 APK 模式（不变）
apk-test run --apk app.apk --device 45a2cacc
```
