# 兼容性问题修复文档

## 改动概述

修复了 `core.py` 中 4 个兼容性问题，涉及进程检测、安装超时、前台检测和 ANR 日志干扰。

---

## 改动详情

### 1. `check_process` — pidof + ps + pgrep 三重兜底

**问题**：`pidof` 命令在旧版 Android（API < 26）或精简系统上不可用，导致进程检测失效。

**改动**：增加 `ps -A -o NAME` 和 `pgrep -f` 两种兜底方式。

```python
def check_process(device, package_name):
    # 方式1: pidof（Android 8+ 支持）
    result = adb_cmd(device, ["shell", "pidof", package_name])
    if result.stdout.strip():
        return True
    # 方式2: ps 兜底（兼容旧版 Android 或精简系统）
    result = adb_cmd(device, ["shell", "ps", "-A", "-o", "NAME"])
    if result.returncode == 0:
        for line in result.stdout.splitlines():
            if package_name in line.strip():
                return True
    # 方式3: pgrep 兜底（部分系统支持）
    result = adb_cmd(device, ["shell", "pgrep", "-f", package_name])
    if result.stdout.strip():
        return True
    return False
```

### 2. `install_apk` — 动态计算安装超时

**问题**：`pm install` 固定超时 120 秒，大 APK（>200MB）或慢速模拟器可能不够。

**改动**：新增 `calc_install_timeout` 函数，根据 APK 大小和 Android 版本动态计算超时。

**超时配置表**：

| APK 大小 (MB) | 基础时间 (s) |
|--------------|-------------|
| ≤ 50         | 30          |
| ≤ 100        | 45          |
| ≤ 200        | 60          |
| ≤ 512        | 120         |
| ≤ 1024       | 300         |
| ≤ 2048       | 600         |
| ≤ 5120       | 900         |
| ≤ 10240      | 1200        |

| Android 版本 | 时间倍率 |
|-------------|---------|
| 4-7         | 3.0     |
| 8-9         | 2.0     |
| 10-11       | 1.5     |
| 12+         | 1.0     |

**公式**：`timeout = base_time × ver_ratio`（最小 60s）

`push` 超时单独设为 `min(install_timeout, 60)` 秒。

### 3. `launch_app` — 启动时清空 logcat

**问题**：`check_anr` 使用 `logcat -d` 不会清空缓冲区，之前其他应用的 ANR 日志可能导致误判。

**改动**：在启动应用前执行 `logcat -c` 清空缓冲区。

```python
def launch_app(device, package_name, launch_activity=None):
    # 清空 logcat 缓冲区，避免旧日志干扰 ANR 检测
    adb_cmd(device, ["shell", "logcat", "-c"])
    ...
```

### 4. `get_foreground_package` — 增加 `dumpsys window displays` 兜底

**问题**：Android 15（API 35）上 `dumpsys activity activities` 和 `dumpsys window windows` 的输出格式变更，无法正确解析前台包名。

**改动**：增加 `dumpsys window displays` 作为首选方式（Android 15+ 推荐），失败后依次降级。

```python
def get_foreground_package(device):
    # 方式1: dumpsys window displays（Android 15+ 推荐）
    result = adb_cmd(device, ["shell", "dumpsys", "window", "displays"])
    for line in result.stdout.splitlines():
        m = re.search(r"mCurrentFocus=(\S+)/", line)
        if m:
            return m.group(1)

    # 方式2: dumpsys activity activities（传统方式）
    result = adb_cmd(device, ["shell", "dumpsys", "activity", "activities"])
    for line in result.stdout.splitlines():
        if "mResumedActivity" in line or "mFocusedActivity" in line:
            m = re.search(r"(\S+)/(\S+)", line)
            if m:
                return m.group(1)

    # 方式3: dumpsys window windows（兜底）
    result2 = adb_cmd(device, ["shell", "dumpsys", "window", "windows"])
    for line in result2.stdout.splitlines():
        if "mCurrentFocus" in line:
            m = re.search(r"(\S+)/", line)
            if m:
                return m.group(1)

    return ""
```

### 5. `check_crash` — 前台检查仅警告（之前已改）

**问题**：Android 15 上 `get_foreground_package` 返回空，导致应用被误判为闪退。

**改动**：以进程存活为主要判断依据，前台检查仅输出警告，不再导致测试失败。
